# Shopify Return-to-Subscription Safeguard Agent (n8n Workflow)

An enterprise-grade, asynchronous n8n automation engine that detects product returns from platforms like AfterShip, Loop, or ReturnGO, cross-references active customer subscriptions in Recharge, and executes precise `CANCEL` or `PAUSE` actions to prevent merchant chargebacks and double-billing leaks[cite: 5, 7].

---

## 🏗 Architecture & Layering Design

This workflow follows a 5-tier deterministic execution architecture designed to handle rate limits, API failures, and webhook retries gracefully[cite: 5]:

1. **Layer 1: Ingress & Idempotency Gate:** Acknowledges incoming webhooks in <100ms with HTTP 200 to prevent sender retries, enforcing deduplication via `return_id` checks against Google Sheets[cite: 5].
2. **Layer 2: Normalization & Intent Classification:** Standardizes line items, normalizes emails, and classifies return actions (`CANCEL`, `PAUSE`, or `NO_OP`)[cite: 4, 5].
3. **Layer 3: State Synchronization & Context Enrichment:** Queries Recharge API for active customer subscriptions and filters exact matches using `external_product_id.ecommerce`[cite: 4].
4. **Layer 4: Mutation Dispatch:** Executes transactional HTTP requests to Recharge endpoints with idempotency headers[cite: 4, 5].
5. **Layer 5: Audit Observability & Telemetry:** Records all execution states to Google Sheets Audit Logs and routes API exceptions to Discord webhook alerts[cite: 4, 5].

## 🛠 Required Credentials & Services

| Service | Credential Type in n8n | Permissions / Scope |
| :--- | :--- | :--- |
| **Recharge API** | HTTP Header Auth (`X-Recharge-Access-Token`) | `read_subscriptions`, `write_subscriptions`[cite: 5] |
| **Google Sheets** | Google API Service Account | Read/Write access to Audit & Dedup sheets[cite: 5] |
| **Discord** | HTTP Header Auth / Webhook URL | Channel post permissions for failure alerts[cite: 4, 5] |

## 🚀 Setup & Installation Instructions

1. **Import Workflow:**
   * Open your n8n instance[cite: 5].
   * Click **Workflow** -> **Import from File**.
   * Select `workflow.json` from this repository[cite: 5].

2. **Configure Environment / Credentials:**
   * Attach your **Recharge API** credentials to the HTTP Request nodes[cite: 4, 5].
   * Set your **Google Sheets Service Account** and update the document IDs for `Dedup_Gate` and `Audit_Log`[cite: 4, 5].
   * Attach your **Discord Webhook URL** to the error alerting node[cite: 4, 5].

3. **Register Webhook:**
   * Copy the URL generated by the `Return_Approved` node[cite: 4, 5].
   * Register this URL as a webhook in your returns portal (AfterShip, Loop, or ReturnGO) under event `return.approved`[cite: 5].

## 🧪 Testing Checklist

- [x] **Idempotency Check:** Re-sending the same webhook payload triggers the `Dedup_Gate` shield and exits without duplicate API mutations[cite: 5].
- [x] **One-Time Purchase Filtering:** Returning a non-subscription line item gracefully logs `ONE_TIME_PURCHASE` and terminates[cite: 4, 5].
- [x] **Multi-Subscription Filtering:** Correctly isolates and modifies only the subscription matching the returned product ID, leaving other active subscriptions untouched[cite: 4].
- [x] **Error Handling:** Simulated API credential failures route directly to the Discord alert pipeline[cite: 4, 5].
